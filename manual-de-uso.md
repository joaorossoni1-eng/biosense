# Manual de uso — BioSense: O que eu sinto?

## 1. Requisitos

| Item | Mínimo |
|---|---|
| **Aparelho** | Tablet, celular ou computador fabricado de 2018 em diante |
| **Navegador** | Chrome, Edge, Safari ou Firefox atualizados (precisa ter WebGL, presente em todos os navegadores modernos) |
| **Internet** | Necessária só no **primeiro acesso**. Depois, funciona sem internet |
| **Som** | Alto-falante ou fone (opcional; o app funciona sem som) |
| **Tela** | Funciona de 360 px (celular) a telas grandes. Recomendado: tablet de 8 a 10 polegadas |

## 2. Como abrir

1. Acesse **https://joaorossoni1-eng.github.io/biosense/**
2. Espere o boneco aparecer (alguns segundos no primeiro acesso).

### Instalar no tablet (para usar sem internet)

- **Android (Chrome):** menu ⋮ → **Adicionar à tela inicial** → **Instalar**.
- **iPad/iPhone (Safari):** botão Compartilhar → **Adicionar à Tela de Início**.
- **Computador (Chrome/Edge):** ícone de instalar na barra de endereço.

Depois de instalado e aberto uma vez com internet, o BioSense abre pelo ícone mesmo offline.

## 3. A tela

```
┌───────────────────────────────────────────────────────────┐
│ BioSense      [Contar | Descobrir]     🔊   〰   ⓘ        │  ← topo
├──────────────────────────────┬────────────────────────────┤
│ [Menino | Menina]            │  ① Onde? ② O quê? ③ Quanto?│  ← progresso
│                              │                            │
│        boneco 3D             │   pergunta + botões        │
│   (toque para escolher,      │                            │
│    arraste para girar)       │                            │
│                    ↺  ↻      │      [Voltar] [Continuar]  │
└──────────────────────────────┴────────────────────────────┘
```

No celular, o boneco fica em cima e os botões embaixo.

## 4. Controles

| Controle | Onde | O que faz |
|---|---|---|
| **Contar / Descobrir** | Topo | Troca entre comunicar uma sensação e aprender sobre ela |
| 🔊 **Som** | Topo | Liga ou desliga todas as falas |
| 〰 **Movimento** | Topo | Liga ou para animações (respiração do boneco, transições) |
| ⓘ **Informações** | Topo | Orientações para adultos |
| **Menino / Menina** | Canto do boneco | Troca o boneco |
| ↺ ↻ **Girar** | Embaixo do boneco | Gira o boneco 90°. Também dá para arrastar com o dedo ou o mouse |
| 🔊 **Ouvir de novo** | Ao lado de cada pergunta | Repete a fala |
| **Voltar / Continuar** | Embaixo do painel | Anda entre as etapas. "Continuar" só acende depois de uma escolha |

**Teclado:** `Tab` anda entre os botões, `Enter` ou `Espaço` escolhe.

As escolhas de som, movimento e boneco ficam salvas no aparelho.

## 5. Passo a passo

1. **Onde?** Toque numa parte do boneco ou num dos 9 botões (inclui "Corpo todo"). A parte acende devagar.
2. **O quê?** Escolha uma das 6 sensações.
3. **Quanto?** Escolha pouco (●○○), médio (●●○) ou muito (●●●). A parte do boneco muda para a cor do nível.
4. **Resumo:** aparece e é falada a frase completa. Opções: ouvir de novo, saber mais, contar outra coisa ou trocar a resposta.

## 6. Solução de problemas

| Problema | O que fazer |
|---|---|
| **O boneco não aparece** (área vazia) | Atualize a página. Se continuar, o navegador pode estar com WebGL desligado: teste em outro navegador (Chrome) ou atualize o atual |
| **Não sai som** | Veja se o botão 🔊 está ligado e se o volume do aparelho está alto. No iPhone/iPad, desligue o modo silencioso. A primeira fala só toca depois do primeiro toque na tela (regra dos navegadores) |
| **A voz soa robótica ou em outro idioma** | O app usa a voz do aparelho. Em Configurações → Idioma/Texto para fala, instale a voz **Português (Brasil)** |
| **Não funciona sem internet** | Abra o app uma vez com internet e espere carregar por completo. Depois feche e teste offline |
| **O toque no boneco escolhe a parte errada** | Gire o boneco para deixar a parte de frente, ou use os botões do painel |
| **Ficou lento** | Toque no botão 〰 para parar o movimento. Feche outras abas |
| **Quero recomeçar** | No resumo, toque em "Contar outra coisa", ou atualize a página |

## 7. Privacidade

Sem login, sem anúncios, sem chat, sem coleta de dados. Nada do que a criança escolhe é gravado ou enviado.
